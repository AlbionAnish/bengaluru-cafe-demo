# Bengaluru Cafe — independent website concept

This is an unsolicited concept website created by Albion Anish as a freelance portfolio demo. It is not affiliated with or endorsed by Bengaluru Cafe.

The business name, public Instagram handle, cuisine positioning, and areas listed in the location section were drawn from the business's public Instagram profile. Menu copy and all photography are illustrative placeholders and should be confirmed or replaced by the business before any production use.

## Preview locally

Open index.html in a browser. This is a static page with no build step or third-party JavaScript dependencies. Google Fonts and Unsplash-hosted images are loaded remotely.
